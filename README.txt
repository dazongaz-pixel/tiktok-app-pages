TikTok Direct Post Mini — GitHub Pages

Загрузите index.html, terms.html и privacy.html в корень нового публичного репозитория.
В GitHub откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
После публикации адреса будут вида:
https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/terms.html
https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/privacy.html

Перед подачей в TikTok замените контактные заглушки реальными данными и проверьте, что политика соответствует реальной обработке данных. Не публикуйте Client secret или OAuth-токены.
